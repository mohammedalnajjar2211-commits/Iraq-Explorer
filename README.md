# Iraq Explorer V7 Fixed
نسخة مصححة بعد اكتشاف خلل JavaScript في V6 كان يمنع تشغيل الخريطتين واللغات والشخصيات.

## ما تم إصلاحه
- إعادة بناء js/app.js من الصفر بدون خطأ syntax.
- الخريطة الرئيسية تعمل عبر Leaflet + OpenStreetMap مع وضع القمر الصناعي Esri.
- خريطة العراق في الواجهة تستخدم خريطة محافظات العراق الحقيقية من Wikimedia مع نقاط تفاعلية.
- اللغات: العربية، الكردية، الإنجليزية، السويدية، الألمانية، الفرنسية، التركية.
- إعادة قسم العلماء والملوك والرؤساء والتبويبات.
- إعادة المطارات والسياحة والآثار والأماكن المقدسة.
- إصلاح نافذة معلومات الخريطة وبطاقات السياحة.

ارفع جميع الملفات والمجلدات إلى جذر مستودع GitHub Pages واستبدل النسخة القديمة بالكامل.
